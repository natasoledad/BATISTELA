# Site Batistela: regras do repositório

Site institucional da Batistela Gestão Empresarial (Astro, GitHub Pages). Fica fora da plataforma GADE: só aponta para os produtos dela. Conversa, textos e commits em português do Brasil.

## Início de cada sessão (obrigatório)

1. **Antes de qualquer tarefa, pergunte:** "Já finalizamos a conversa anterior? Tem o print da atualização dessas modificações no servidor?"
2. **Só avance** com um "sim", ou quando chegar o print mostrando que a última versão do GitHub está publicada no site. Se a resposta for não, ajude primeiro a concluir a publicação.
3. **Leia os registros, não a conversa:** este arquivo, `README.md` e `PENDENCIAS.md`. Resuma em poucas linhas o estado e o que está pendente, e então siga.
4. **Ao terminar**, atualize `PENDENCIAS.md` com o que foi feito e o que falta.
